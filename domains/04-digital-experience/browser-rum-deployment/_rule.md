## Scoring Summary

| Level | Summary |
|---|---|
| 1 | No NR Browser agent deployed. Digital experience quality is invisible — issues discovered via user complaints. |
| 2 | NR Browser agent deployed on primary customer-facing web properties. Core Web Vitals data visible in NR Browser UI but not reviewed operationally. No p75 target defined. |
| 3 | NR Browser Pro deployed across all customer-facing web properties. LCP, INP, and CLS tracked at p75 with defined targets. Trends reviewed on engineering ops cadence. |
| 4 | NR Browser distributed tracing enabled — user interactions traceable to specific back-end APM service calls. Experience SLOs defined on at least one critical user journey. |
| 5 | Experience SLOs with error budgets govern front-end release decisions. AI-driven behavioral anomaly detection active. CWV degradation triggers automated engineering escalation. |
