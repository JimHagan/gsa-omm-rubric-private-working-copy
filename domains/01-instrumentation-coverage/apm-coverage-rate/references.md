# References

## Observability Maturity: Introduction and Value Drivers
**URL:** https://docs.newrelic.com/docs/new-relic-solutions/observability-maturity/introduction/
**Summary:** New Relic's primary observability maturity framework documentation. Defines the three value driver packages — Business Uptime, Engineering Excellence, and Digital Experience — and their associated use cases. Provides the overarching framework authority for how maturity levels connect to business outcomes.

## Observability Maturity Architecture Overview
**URL:** https://docs.newrelic.com/docs/new-relic-solutions/observability-maturity/observability-maturity-architecture/introduction/
**Summary:** Defines Intelligent Observability as the Level 0 foundation for New Relic's maturity architecture and describes the four-level progression (Reactive → Responsive → Proactive → Mastery). The source for the maturity level vocabulary used throughout rubric level descriptions.

## Intelligent Observability: Foundation Level Guide
**URL:** https://docs.newrelic.com/docs/new-relic-solutions/observability-maturity/intelligent-observability/introduction/
**Summary:** New Relic's guide to the Intelligent Observability foundation level. Covers team tag coverage, environment tag coverage, APM criticality tagging, and uninstrumented entity detection as the baseline requirements for entity governance. The scorecard rule NRQL queries for tag coverage and uninstrumented entity checks are documented here.

## Observability Maturity for Organizations with New Relic
**URL:** https://newrelic.com/blog/best-practices/observability-maturity-for-organizations
**Summary:** Practical guide tracing the observability maturity journey from basic component monitoring (CPU/memory ping checks) through enhanced observability (APM, distributed tracing) to correlated telemetry and business outcome measurement. Provides accessible language for L1→L2 transition descriptions.
