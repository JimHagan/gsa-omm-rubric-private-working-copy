## Scoring Summary

| Level | Summary |
|---|---|
| 1 | No NR Browser agent deployed on any web property. Digital experience is a blind spot. |
| 2 | NR Browser agent deployed on primary customer-facing web properties (main e-commerce site, primary login flow). Secondary properties not covered. |
| 3 | NR Browser agent (Pro tier) deployed across all customer-facing web properties. Coverage includes secondary domains, localised variants, and partner-facing surfaces. |
| 4 | All web properties including internal tools instrumented. Browser agent deployment automated via tag manager or build pipeline. |
| 5 | Browser agent provisioning self-managing. New web properties inherit agent deployment on first build. No manual instrumentation gap possible. |
