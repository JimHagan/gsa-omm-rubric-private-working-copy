## Scoring Summary

| Level | Summary |
|---|---|
| 1 | No NR Mobile agent deployed. Crashes and errors discovered via App Store reviews or support tickets. |
| 2 | NR Mobile agent deployed on the primary revenue-generating app. Secondary apps, alternative platforms (tablet, TV), or white-label variants not instrumented. |
| 3 | All customer-facing native apps (iOS and Android) instrumented. Crash-free rate and HTTP response time tracked. |
| 4 | All apps including internal enterprise apps instrumented. Mobile agent integrated into CI/CD pipeline — new releases automatically include the agent. |
| 5 | Mobile agent inclusion fully automated in the build process. All new app variants inherit instrumentation. No manual step required. |
