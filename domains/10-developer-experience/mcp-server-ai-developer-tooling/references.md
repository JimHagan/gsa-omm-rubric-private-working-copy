# References

## Platform Engineering Maturity Model
**URL:** https://tag-app-delivery.cncf.io/whitepapers/platform-eng-maturity-model/
**Summary:** CNCF's authoritative maturity model for internal developer platforms. Defines five maturity levels (Provisional → Operational → Scalable → Optimizing → Objective) and articulates the golden path concept — a paved road of curated tooling choices that reduces cognitive load for service teams. Primary authority for platform-as-a-product criteria at L4 and golden path adoption criteria.
